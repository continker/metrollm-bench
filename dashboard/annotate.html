MetroLLM-Bench — Judge Calibration

Human evaluation of LLM judge accuracy

What is this?

We built a benchmark that tests whether language models can serve as transit kiosk assistants — answering questions about routes, fares, disruptions, and policies for real metro systems.

An LLM judge (Claude Haiku) automatically scores whether the model's responses are semantically correct. Your job is to check whether the judge got it right.

What you'll see

For each case, you'll see:

  • A question — the specific rubric being evaluated (e.g., "Did the model correctly describe the disruption?")
  • Case context — what the passenger scenario was (which stations, what disruption, what the correct answer should be)
  • Model response — what the AI model actually said or submitted
  • Route map — an interactive map showing the metro network and planned route (right panel)

How to rate

Read the question, compare the model response against the context and ground truth, then pick:

  • 0 — The model didn't address this at all, or got it wrong
  • 1 — Partially correct — the model mentioned the right topic but missed key details or got something wrong
  • 2 — Fully correct — the model's response accurately addresses the rubric question
Tip: Focus on whether the information is correct, not whether it's well-written. A short, accurate answer is a 2. A long, eloquent answer with wrong facts is a 0. When in doubt between 1 and 2, ask yourself: "would a passenger be misled?"
